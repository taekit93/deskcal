DeskCal

개인정보처리방침

시행일 2026-09-30

DeskCal(이하 "앱")은 Google 캘린더와 Google Tasks를 Windows 바탕화면에 보여주는 데스크톱 앱입니다. 이 방침은 앱이 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

앱에는 서버가 없습니다. 앱은 사용자의 PC에서 Google API와 직접 통신하며, 개발자는 사용자의 데이터를 수집하거나 전송받거나 저장하지 않습니다.

1. 앱이 접근하는 Google 데이터

권한 (OAuth 스코프)접근하는 데이터사용 목적
calendar.readonly캘린더 목록, 캘린더 색상, 일정(제목·시간·링크)월간 달력과 날짜별 일정 목록 표시. 일정을 만들거나 수정·삭제하지 않습니다.
tasks할 일 목록, 할 일(제목·마감일·메모·완료 상태)할 일 목록 표시, 사용자가 체크한 할 일을 완료 또는 미완료로 변경

2. 데이터 저장 위치

  • 로그인 토큰(refresh token): Windows 자격 증명 관리자에 저장됩니다. Windows가 사용자 계정 기준으로 암호화합니다.
  • 캐시: 오프라인에서도 마지막 화면을 보여주기 위해, 받아 온 일정과 할 일을 %APPDATA%\kr.taekit93.gcalwidget\cache.json에 저장합니다.
  • 설정: 보기 모드, 테마, 숨긴 캘린더 등은 같은 폴더의 settings.json에 저장됩니다.
  • 이 데이터는 사용자의 PC를 벗어나지 않습니다.

3. 제3자 제공과 공유

앱은 Google 사용자 데이터를 제3자에게 판매하거나 제공하거나 공유하지 않습니다. 광고, 분석 도구, 사용 통계 수집 기능이 없습니다.

4. Google API 서비스 사용자 데이터 정책 준수

DeskCal이 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

5. 데이터 삭제와 권한 철회

  • 위젯 설정 또는 트레이 메뉴에서 로그아웃하면 저장된 로그인 토큰이 삭제됩니다.
  • 캐시와 설정은 %APPDATA%\kr.taekit93.gcalwidget\ 폴더를 지우면 삭제됩니다. 앱을 제거한 뒤 지우면 됩니다.
  • Google 계정의 서드파티 액세스 설정에서 언제든 DeskCal의 권한을 철회할 수 있습니다.

6. 문의

이 방침이나 앱에 대한 문의는 GitHub 저장소의 Issues로 남겨 주세요.

7. 변경

방침이 바뀌면 이 페이지에 게시하고 시행일을 갱신합니다.

Privacy Policy

Effective 2026-09-30

DeskCal ("the app") is a desktop app that shows Google Calendar and Google Tasks on the Windows desktop. This policy explains how the app handles Google user data.

The app has no server. It talks to Google APIs directly from your PC, and the developer does not collect, receive or store any of your data.

1. Google data the app accesses

Permission (OAuth scope)Data accessedPurpose
calendar.readonlyCalendar list, calendar colors, events (title, time, link)Show the month view and each day's events. The app never creates, edits or deletes events.
tasksTask lists and tasks (title, due date, notes, status)Show tasks and mark tasks you check as completed or not completed

2. Where data is stored

  • Sign-in token (refresh token): stored in Windows Credential Manager, encrypted by Windows for your user account.
  • Cache: fetched events and tasks are saved to %APPDATA%\kr.taekit93.gcalwidget\cache.json so the last view is available offline.
  • Settings: view mode, theme, hidden calendars and similar options are saved to settings.json in the same folder.
  • None of this data leaves your PC.

3. Third parties and sharing

The app does not sell, transfer or share Google user data with any third party. It contains no ads, analytics or usage tracking.

4. Google API Services User Data Policy

DeskCal's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. Deleting data and revoking access

  • Signing out from the widget settings or the tray menu deletes the stored sign-in token.
  • Delete the %APPDATA%\kr.taekit93.gcalwidget\ folder to remove the cache and settings, for example after uninstalling.
  • You can revoke DeskCal's access anytime in your Google Account's third-party access settings.

6. Contact

For questions about this policy or the app, open an issue in the GitHub repository.

7. Changes

If this policy changes, the new version will be posted on this page with an updated effective date.
